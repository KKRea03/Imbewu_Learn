# Imbewu_Learn

A platform for preserving and sharing indigenous knowledge — connecting
Educators (who share knowledge), Knowledge Keepers (who verify
it), and Learners (who learn from it), with an Azure AI pipeline
that turns verified knowledge into lessons, summaries, quizzes, and
translations.

Plain HTML / CSS / JavaScript frontend. Supabase (Postgres + Auth +
Storage + Edge Functions) backend. No build step, no framework.
